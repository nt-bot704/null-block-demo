이 저장소는 브랜치나 PR 없이 `main`에 바로 커밋하고 push합니다. 아래 순서대로 진행하고, 한 단계라도 막히면 거기서 멈추고 이유를 보고하세요.

1. **확인**: `git status -sb`와 `git diff`로 변경 내용을 봅니다. 현재 브랜치가 `main`이고 변경이 있어야 다음 단계로 갑니다. 다른 브랜치이거나 변경이 없으면 그 사실만 보고하고 끝냅니다.
2. **검사**: 바뀐 `.js` 파일마다 `node --check <파일>`을 실행합니다. 모두 통과해야 다음 단계로 갑니다.
3. **커밋**: 이번 작업에 속한 파일만 경로를 지정해 `git add`합니다. 메시지는 한국어로 씁니다.
   - 첫 줄: 무엇을 했는지 한 줄 (예: `게임 오버 글자 뒤에 어두운 배경 추가`)
   - 빈 줄 다음, 바뀐 점을 `- ` 목록으로 짧게
   - 맨 끝: 이 세션이 지정한 `Co-Authored-By` 줄
   - 인자가 있으면(`$ARGUMENTS`) 첫 줄을 쓸 때 참고합니다.
4. **push**: `git push origin main`을 실행하고, `git status -sb`가 `## main...origin/main`(앞서거나 뒤처짐 없음)으로 나오면 끝입니다. 원격이 앞서 있어 거절되면 강제 push하지 말고 보고합니다.
5. **보고**: 커밋 해시와 제목, push 범위(`이전..이후`)를 한두 줄로 알립니다.
